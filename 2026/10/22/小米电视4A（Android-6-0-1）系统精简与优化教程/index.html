设备：小米电视4A，Android 6.0.1（API 23），1GB 内存，无 root，开启开发者模式（开启usb调试、adb调试【可选】），已安装第三方launcher。
现状：已完成 36 个系统包的 adb shell pm uninstall --user 0 用户级卸载，系统设置、输入源、遥控器、播放均正常。

恢复优先级提醒

  • 遇到下载异常：先恢复 com.android.providers.downloads。
  • 遇到桌面异常/默认桌面丢失：恢复 com.mitv.tvhome，或确认 Projectivy 等第三方桌面仍可用。
  • 遇到 U 盘/媒体扫描/存储访问异常：检查 com.xiaomi.mitv.media 与 com.xiaomi.mitv.mediaexplorer（后者你已恢复）。
  • 恢复 /data/app 下的包：原路径可能已被清理，优先用之前 adb pull 备份的 APK；没有备份时，/system 下的包通常仍可 adb install 恢复。

特别注意：com.mitv.tvhome（原生桌面）和 com.android.providers.downloads（下载提供者）也在已卸载列表中。前者卸载前需要确认已经安装第三方launcher不如： ATVlauncher、leanbakc、 Projectivy 等第三方桌面替代，后者如遇下载异常可用 adb install -r -d --user 0 恢复。

五、执行顺序建议

  1. 先做第一批 settings 参数：动画归零 + 后台进程限制为 2，这两条对 1GB 内存的流畅度提升最直接。
  2. **再做第二批 force-stop**：对 tvmanager、codec.update 和第三方常驻应用逐条压制，每条后测试设置与桌面。
  3. 最后做第三批开发者选项：手动确认动画与 GPU 渲染设置。
  4. 每次只改一项，改完立即测试：设置各页面、桌面、遥控器、本地播放。异常立即撤销或重启。

精简已进入尾声，继续动系统包的收益极低、风险极高。把精力放在 settings 调优和对第三方应用的按需管理上，是这台 1GB 内存 Android 6 电视当前最安全、最有效的优化路径。

  • settings 参数扩展：新增 auto_sync=0，尝试写入速度模式与硬件加速，每条写入后 settings get 读回验证，不生效只警告不中断。
  • 新增缓存清理：pm trim-caches 清理所有应用缓存（不删数据），清空 /data/local/tmp，清空 logcat。
  • 新增状态快照：记录 low_ram、存储、内存、屏幕分辨率/密度，执行后可在日志里对比。
  • 新增 force-stop 模块：系统服务（tvmanager、codec.update）和第三方常驻应用（亚马逊桌面、投屏接收器、文件管理器、v2ray、商店、影视、VLC、远程输入、监控）分开确认，每条后检查进程是否真的停掉。
  • 新增开发者选项手动清单：强制GPU渲染 无法通过 settings put 可靠写入，脚本改为提示用户手动开启并核对。
  • 新增重启提示：settings 部分参数需要重启才完全生效，脚本末尾询问是否 adb reboot。

执行顺序

  1. 检查 ADB → launcher → 核心包（三道关卡，任一失败直接退出）
  2. 总确认 I UNDERSTAND
  3. 备份包列表
  4. [1] settings → [2] 缓存清理 → [3] 状态快照 → [4] force-stop 系统服务 → [5] force-stop 第三方（均为可选确认）
  5. [6] 卸载安全包 → 高风险包二次确认 RISKY
  6. 验证 → 开发者选项清单 → 可选重启

所有操作写入 optimize_logs/optimize_<时间戳>.log，备份文件同目录。
