飞智 冰原狼2手柄使用说明

技术参数

  • 蓝牙： Bluetooth 5.0

  • 使用距离： < 10m

  • 电池：

      类型：锂电池
  容量：800 mAh
  充电：2 小时
  充电电压：5 V
  充电电流：800 mA
  工作电流：< 45 mA
  待机电流： < 10 µA

  温度范围： 5°C - 45°C

首次连接方式

蓝牙

背部挡位调至蓝牙 —>> 按 一下 🏠键（白灯长亮） —>> 长按🏠键3秒（白灯开始闪烁） —>> 设备可以搜索并连接到到 Xbox Wireless Controller 蓝牙设备

二次连接手柄开机可自动连接。要特别注意：如果连接过设备一，再连接设备二时需要先在设备一忽略手柄蓝牙，不然设备二无法连接。

2.4G无线接收器连接

背部挡位调至 USB接收器 —>> 关机状态 长按 🏠键（白灯快闪）—>> 手柄USB接收器插入设备开始配对

NS

Switch进入 更改握法/顺序 –>> 背部挡位调至 NS —>> 按 一下 🏠键（蓝灯常量）

基本操作

  • 开机： 背部选择对应模式，按 一下 🏠键

  • 关机： 任意切换背部挡位（或者无操作等15分钟自动关机）

  • Xinput: 长按 O + X 键，指示灯亮白色⚪

  • Dinput: 长按 O + A 键，指示灯亮蓝色🔵

  • 低电量： 指示灯红色闪烁

  • 关机充电指示灯：充电红色🔴常亮， 充满变绿色🟢常亮

  • 震动调节： 长按 O + 左摇杆向上/下推动，可提高/降低针对力度

  • 板载配置方案切换： select + A/B/X/Y 可切换到对应键存储的配置

  • 安卓智连模式（横屏非原生游戏）： 蓝牙 挡，点按开机，长按 O + Y（指示灯亮蓝色🔵）

  • 安卓传统模式（原生游戏）：蓝牙 挡，点按开机，长按 O + Y（指示灯亮蓝色🔵）

【Xinput: 新街口，适配大多数现代游戏。； Dinput： 老旧接口，适配复古游戏、街机等。飞智空间链接需要开启Dinput模式】

自定义

使用 飞智空间
win安装飞智空间,mac推荐使用Parallels Desktop虚拟机安装，要注意usb和蓝牙里将手柄加载到虚拟机中。需要开启Dinput模式才能链接飞智空间

  • 按键映射
  • 宏定义
  • 体感映射
  • 遥感调节

手柄端快捷设置

连点

设置：点按 O + <需要连点的按键> (点按连点状态的按键时指示灯会闪烁)

取消：点按 O + <需要取消连点的按键>

宏（只对 M1/M2 按键生效）

录制： 长按 O + M1/M2 (指示灯蓝白闪烁🔵⚪) —>> <按 需要录制的按键组合> —>> 按对应的 M1/M2 结束录制

取消： 长按 O + M1/M2

注意： 如果仅录制一个键,则会把M1/M2映射为该键

体感/扳机矫正

开机状态 —>> 长按 select + start + 十字键上键盘 3秒（指示灯红色🔴慢烁） —>> 拿起 短按（按满）LT/RT 2次 —>> 分别旋转左右摇杆 2圈 —>> 短按 select + start + 十字键上键盘退出矫正模式完成矫正

遥感矫正

开机状态 —>> 长按 select + start + 十字键上键盘 3秒（指示灯红色🔴慢烁） —>> 平放桌面后自动矫准，1秒后自动退出矫正模式

恢复出厂设置

开机状态 —>> 长按 select +LB + RB 5秒（手柄震动一下提示

DFU模式

开机状态 —>> 长按 LB + RB + START 5秒，强制进入Bootloader模式
