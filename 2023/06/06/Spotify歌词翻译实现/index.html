Spotify歌词翻译实现

发布于 2023-06-06 17:06 Spotify 

需要准备：

  • 百度翻译API
    注册 百度翻译个人开发者，然后开通api申请百度翻译的 appid 和 key。接下来要在脚本文件里使用。建议申请高级版，标准版可能不够用。
  • 网络调试工具
    这类工具软件有很多，能执行脚本的都可以，任选其一：
    • 网络调试类： Surge \ Loon \ Shadowrocket \ QuantumultX \ Stash 等；
    • 抓包工具： StormSniffer \ Hodor 等；

配置步骤：

脚本版：

  1. 在网络工具中 添加脚本 （每个软件添加的方式不一样，配置方式大同小异。）
  2. 主要配置：
    类型：http-response
    表达式：^https:\/\/spclient\.wg\.spotify\.com\/color-lyrics\/v2\/track\/
    脚本路径:https://raw.githubusercontent.com/app2smile/rules/master/js/spotify-lyric.js
    需要body:开启
    参数:appid=xx&securityKey=xxx（注意将其中的 appid 和 securityKey 替换为自己的）
  3. 在MITM中添加域名：spclient.wg.spotify.com
    开启 mitm 和脚本即可正常使用

脚本来源 app2smile，如需要歌词翻译同行显示，使用这个脚本

插件版：

使用时需要根据自己申请的百度翻译api修改argument。

· plugin格式：直接将以下内容保存为.plugin格式文件直接使用。

· sgmodule格式：直接将以下内容保存为.sgmodule格式文件直接使用。

QuantumultX的配置相对没这么方便，这里单独列出来：

  1. 打开QuantumultX脚本页面（底部导航栏右边第二个图标😳）- 编辑脚本（点击页面的右下角图标）
  2. 清空脚本内容并将粘贴以下内容，并将申请的appid和securityKey密钥正确填入。
  3. 保存文件输入文件名称，比如spotifyLyric.js
  4. 添加重写规则：
    type: script-response-body
    URL to match: ^https:\/\/spclient\.wg\.spotify\.com\/color-lyrics\/v2\/track\/
    Script:spotifyLyric.js(这里要和你保存的文件名一致，这个文件的保存路径时~/QuanmultX/Scrpits)
  5. 在MITM中添加域名：spclient.wg.spotify.com

Spotify 歌词翻译使用百度翻译 api 的几点注意事项

这两天发了 spotify 歌词翻译以后，部分网友私信协助其进行了配置，因为私信较多，可能在私信的过程中部分网友收到的代码里包含了我的百度翻译 api。今天发现欠费了……所以想给大家一些提示：

  • 流量

    通用翻译 API 标准版免费调用量调整为 5 万字符/月，高级版免费调用量调整为 100 万字符/月。
    请选择 高级版，标准版可能不够用。
    高级版比标准版相比要求多个了个人认证，需要身份证和手机号。

  • 费用
    百度翻译是可以欠费的！采用的是次日结算的方式，欠费以后服务就被停用了，脚本无法使用翻译功能会提醒你检查 api 和 key 的配置。
  • 必要设置
    可以开通流量提醒、费用提醒。支持设置手机号和邮箱。
