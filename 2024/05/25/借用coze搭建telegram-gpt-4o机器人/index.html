借用coze搭建telegram gpt-4o机器人

发布于 2024-05-25 13:05 telegram chatgpt 

openai开放gpt-4o以后明显使用次数不能满足需求，翻了下，coze又刚好可以提供，还能在telegram、discord里使用。搭了telegram bot挺好用的。
gpt-4o_bot 欢迎试用

创建

  1. 创建coze账号-创建机器人-模型选gpt-4o;
  2. 发布到： bot store \ telegram ;
  3. api 根据个人需求配置
  4. publish
    在步骤2 配置telegram时，需要新建一个bot，@botfather找到token,并完成必要的设置即可

群组中使用的注意事项

  • 给予bot 群组admin权限；
  • bot 设置中关闭group privacy，否则群组中无法相应
  • 其他 名称 图标 介绍 什么的自己完善就可以了
